**Goal:** Replace v1 horizontal lanes (structurally walled on 4-gate: 0/200 seeds, ~5000 order samples, mutual walling under pitch-2) with relays + N-S trunks in inter-band gaps so every hop spans ≤1 gap.

**Architecture:** `expand_gates` gains crossing-relays (`buf = x AND x`, tagged like existing `rep` precedent, one chain per cross-band net); `layout()` routes only local hops reusing the v1 planner core (legality, decay budgets, tap rule, order search): same-band hops go direct (Manhattan L), cross-band hops go driver→gap-trunk→loads. Maze stays deleted; retry/grow/verify untouched.

**Tech Stack:** Python 3, stdlib only. No dependencies added. Minecraft Java 1.20–1.21 export target (unchanged).

**Base:** `phase2-design` as-is. Merge PR #1 first — v2 lamp/`__main__` references assume east-first lamps + port asserts.

**Why v2 (one line):** v1 lanes thread tile columns; gaps (~14 cells, empty by construction) are the only free corridors — so route there.

## Global Constraints

- Flat single-layer: no layers, bridges, or vertical crossovers.
- No new tile types; tile stamps byte-untouched (Phase 1 locked).
- `sim.py` untouched; `layout_retry(verify=True)` is the selector.
- Stations every 14 cells, measured both directions from the trunk feed point (repeaters are one-way: south- + north-facing).
- Taps ONLY at repeater outputs or the trunk feed cell (the only full-strength sources).
- Exactly one lever per input, at its chain head. Trunks at pitch 2.
- Never silent wrong: collisions raise `RuntimeError` into tries/grow retry.
- No minimize guard needed: `sim.layout_retry` minimizes first, `layout()` expands after — verified by reading, not memory.
- Test style: assert-based scripts run via `python <file>`, matching `recipe.py`/`sim.py`/`layout.py`.
- Process calibration: never trust mental tile coordinates — instrument (`dbgrows` pattern) or replicate in probes.
